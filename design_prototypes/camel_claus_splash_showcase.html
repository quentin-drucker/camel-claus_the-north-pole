Recommended startup chain for the web build

0–3 s (depends on network)Custom HTML shellShown instantly from index.html. It shows the concept's loader, driven by Godot's real onProgress(current, total). Only CSS and a few KB of inline SVG/PNG, so it appears in the first paint. Its background color is the boot color.
~0.3–0.6 sEngine bootboot_splash/show_image = false and boot_splash/bg_color = the same color. The canvas fades in over the loader, so you never see a white or black flash.
3–4.5 s, skippablesplash.tscnThe main scene. AnimationPlayer intro whose first frame is the loader's last frame. It loads the menu with ResourceLoader.load_threaded_request while it plays (sync fallback on web).
thenmain_menu.tscnReached through the existing Transition autoload, using the concept's own wipe (shutter, curtain, dive, swipe, iris).

Why a combination, not one or the other

  • The web loader is unavoidable: index.wasm is 39.5 MB, and until it downloads and compiles nothing from Godot can draw. Godot's default shell only shows a bare progress bar. A custom shell (html/custom_html_shell) gives the first 1–10 s a designed look at almost no cost.
  • The Godot intro is where character animation belongs: it can use the real models, the menu diorama and the game's own shaders, and it's the same on desktop builds.
  • The demo's advice holds here: turn off the boot-splash image, match bg_color to the first frame, make splash.tscn the main scene, use AnimationPlayer's animation_finished to move on, and don't preload() the menu in the splash (that would block its first frame).
  • Keep the intro under 4.5 s, skippable on any key, click or tap. Show it in full on first launch only; on later visits play a 1-second logo sting (save a flag in Profile).

Not seeing it while developing

  • In splash.gd: if not OS.has_feature("template"): get_tree().change_scene_to_file.call_deferred(MENU). The template feature is true only in exported builds, so F5 in the editor goes straight to the menu while every export shows the intro.
  • Add a project setting such as camel_claus/always_show_intro to force it on when you're working on the intro itself (or use F6 on splash.tscn, which always plays it).
  • Tests and the balance bot already load main.tscn directly, so they're unaffected.
  • Reduced motion: honour a Settings toggle and, on web, prefers-reduced-motion (read in the HTML shell and passed to Godot via JavaScriptBridge). It shows the final frame for 1 s, then crossfades.
